# EngagePlus WordPress Plugin

Official WordPress plugin for [EngagePlus](https://engageplus.id) - a lightweight, data-agnostic authentication platform supporting any OIDC provider.

## Overview

This repository contains the EngagePlus WordPress plugin, enabling seamless social login integration for WordPress sites using Google, GitHub, Microsoft, LinkedIn, and many more OAuth/OIDC providers.

## Features

- 🔐 **Universal OAuth Support** - Works with any OIDC-compliant provider
- ⚡ **Lightweight** - Minimal performance impact
- 🎨 **Customizable** - Themes, button text, placement options
- 🔄 **Auto User Management** - Automatic WordPress account creation
- 📱 **Responsive** - Works on all devices
- 🔒 **Secure** - PKCE flow, HTTPS required

## Quick Start

1. Install the plugin from `/engageplus` folder
2. Get your Client ID from [engageplus.id](https://engageplus.id)
3. Configure in **Settings > EngagePlus**
4. Add `[engageplus]` shortcode or widget to your site
